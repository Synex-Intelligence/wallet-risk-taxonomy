# Contributing

If you know crypto security, on-chain analytics, wallets, P2P or transaction infrastructure, we would like your input.

You do not need to write a long article.

Useful contributions can be small:

- fix a bad definition
- add a missing risk
- point us to a better source
- add a real public case
- challenge an assumption
- improve an explanation

## What makes a good contribution

Keep it:

- factual
- readable
- useful
- sourceable
- specific

We prefer:

"This pattern can indicate X, but it can also happen because of Y."

over:

"This wallet is definitely malicious."

Crypto risk is rarely that simple.

## Please avoid

Do not submit:

- private user data
- leaked datasets
- API keys
- unsupported accusations
- personal information
- proprietary ChainZap logic

## Style

Write like a smart person explaining something to another smart person.

No legalese.

No crypto hype.

No "revolutionary blockchain security ecosystem."

If a sentence sounds like it belongs in a pitch deck, rewrite it.
