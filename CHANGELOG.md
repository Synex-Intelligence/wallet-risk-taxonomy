# Changelog
 ChainZap research repository and platform interface.

## v0.2 — Web Application Release

Public release of the ChainZap Web App interface and multi-chain address screening tools:

- **Web App Launch:** Added complete web interface with Dashboard, Check Address portal, and History tracking.
- **Multi-Chain Screening:** Support for Ethereum, TRON, and TON address and Tx Hash verification.
- **Risk Classification System:** Integrated real-time risk verdicts (`CLEAR`, `CAUTION`, `HIGH RISK`, `INSUFFICIENT DATA`) with summary Risk Snapshot analytics.
- **Account & Dashboard:** Added Google/Telegram account connections, Pro tier check allowances, shared verification review, and theme customization (Dark, Light, System).
