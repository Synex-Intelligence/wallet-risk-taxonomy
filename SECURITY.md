# Security

Found a security issue related to ChainZap?

Please do not publish sensitive details in a public GitHub Issue.

Send the report privately through our official contact channel on:

https://chainzap.io

Useful reports usually include:

- what you found
- where you found it
- how to reproduce it
- what the possible impact is

If screenshots or logs contain secrets, wallet identifiers or private information, remove them first.

## About this repository

This repository contains public research and documentation.

It does not contain the private ChainZap risk engine, production credentials, internal datasets or proprietary scoring logic.
